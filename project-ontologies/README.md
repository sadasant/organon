# Project ontologies

Project ontologies are source-pinned candidate mappings from one public
repository into Organon's binding vocabulary. They describe the project's own
terms first, identify load-bearing technical and institutional relations, and
then classify each correspondence as exact, refinement, conflict, or unmapped.

They are not adoption manifests. They do not amend Organon, certify a project,
or convert repository self-description into Truth or Evidence. Each remains a
`generated-candidate` until maintainers review and adopt it.
