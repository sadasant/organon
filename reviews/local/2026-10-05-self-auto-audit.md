# Reflexive reference and operative organization

Historical note: this audit records the earlier pause. The later user-authorized full proposal is now in [the PR18 reading packet](./pr18-reading-draft/pr18-source-packet.md). Its distinct proposed ontology/registry and new formal shadow remain unadopted. The earlier 1,975-theorem result below applies to the original source graph; the current audit also imports the new draft and checks 2,079 theorem declarations.

This is a local review on PR18, not a vocabulary promotion. Daniel's latest distinction is the premise: **Self** names reflexive reference, while **Auto** would name operative production. This is an intended technical distinction, not an etymological claim. The earlier proposal to replace Self with Auto has been withdrawn pending review. The canonical ontology and its governed projections remain unchanged.

The two axes must be stated independently. A process may concern the Entity operating it, concern another Entity, be produced through that Entity's own organization, or be produced by an external operator. Same-Entity reference does not establish operative source. An Entity being a causal input or target does not establish that it operates the process. Active need not mean uninterrupted: an episodic occurrence or a recurrence can be operative. External inputs do not exclude operative participation.

## Concrete cases

A camera's own sensed internal State carrying a Representation with Denotation to that very camera can support Self-perception. Recognizing the generic class "camera" in a mirror is insufficient: the Denotation must identify that Entity, not only the category. An external observer attaching a same-camera label to an image supplies external attribution, not the camera's perceptual uptake. A camera that perceptually represents another camera exercises Perception without Self-perception. Camera, model, and mirror examples must identify the persistent perceiving Entity; an isolated model output does not establish it.

A GPS device's own perceptual process may register signals and produce an internal position Representation associated with that device's State. This can support Self-perception without a mind, Agency, or consciousness. A database containing a device's location, or a remote observer assigning that location without device uptake, does not establish its Self-perception. Receiving satellite signals does not invalidate the case: external input and reflexive reference are compatible. Organon must declare which Entity is being located: receiver, vehicle, or another tracked Entity.

An external camera can photograph an Entity whose changing State causes a changed photograph. That causal Difference does **not** establish the photographed Entity as operator of the camera's process. This defeats the first attempted Auto criterion, "Entity's State causally contributes to the output." Role identity alone also fails: a target can be named correctly without producing the process. The revision therefore does not promote either criterion.

## Substantive issues independent of the prefix

D111 must retain its representational contrast, exact outcome Denotation, exact contribution-to-selected-output join, two distinct available alternatives, and internal Body membership when specialized. A broader Governance can remove the internal-only restriction while preserving those operative conditions. Representation requires no mind; representation alone supplies no selection.

D112 currently says **Capability**, but D038 types Capability as Actions an Agent can produce. Internal Activity Selection explicitly need not be Action or Agency. The Lean structure `EmbodiedSelfGovernance` is a proof-carrying configuration of Perspective, selection, scoped governed family and admission; it does not construct canonical Agent/Action Capability. Manifest AC-D1 calls that family a constructive Capability projection. Compilation proves the structure, not the missing canonical typing join. A future repair should type the internal case as Configuration, or deliberately strengthen it to Agent/Action Capability. Configuration preserves its present internal-only meaning.

The existing candidate consciousness structure also depends on Perspective, Recurrent Integration and the exact Perspective-selection join. Factoring general Governance or Self-perception does not establish that candidate and must not erase those premises. Consciousness remains deferred; source dossiers and prior candidate evidence should be retained as history.

Autonomy must not identify an internal-only selected Transformation with a Boundary-crossing Action. A possible valid connection uses distinct occurrences: the selected internal output feeds a discriminating Interpretation, which causally changes the same Entity's exact Action. Each causal seam requires its own named Difference and contribution, with common Direction, Scope and path interpretation. Mere sequence, equality of unrelated outputs, or conjunction with Agency is insufficient. A constructive positive witness and countermodel remain required before promotion.

No blanket replacement is warranted for ordinary **self-description**, **self-reference**, **self-documentation**, **self-authored Rule**, **self-determination**, or named intellectual precedents involving self-reference/autopoiesis. Those usages concern reference, provenance, retained options, or historical vocabulary; none automatically claims an operative-source classifier. The existing `governance` adoption profile concerns institutional governance and is not automatically identical to the proposed causal-selection term.

## Decision remaining

First settle whether useful extra organizational-source semantics remains after the operative conditions already supplied by Perception and Governance. If not, introduce the reflexive relation and Self-perception, repair D112's type, and keep Auto out. If so, state that extra condition concretely and test the external-photograph counterexample before naming it. An operator Specification or a canonical realization gate is not adopted merely to preserve an attractive prefix.

No definitions, registries, formal contracts, source histories, site or PDF artifacts have been changed by this review. The next implementation depends on this conceptual choice.
