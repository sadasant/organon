# Unicode vocabulary candidate atlas

Generated by `python3 scripts/check-unicode-vocabulary.py --write`. Edit the candidate JSON, not this table. **Nonbinding; not a codebook.**

Read the [study](./unicode-vocabulary.md) for method, sources and limits. `trial` means a labelled mnemonic worth testing; `reject` rejects only the displayed candidate; `compose` retains the name and explicit structure rather than proposing a standalone mark.

Coverage: **115 active entries**; **34 trial**, **33 reject**, **48 compose**. No assignment claims semantic equivalence.

Source: ontology v0.20.0 at [b5b80a7](https://github.com/sadasant/organon/commit/b5b80a7df04a240281dbef82924f20a00168b04e). Term links below open the working ontology; use that commit to recover the definitions assessed if the ontology has since changed.
