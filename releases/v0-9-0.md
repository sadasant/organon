# Organon v0.9.0

Organon v0.9 turns the ontology from a carefully ordered document into an inspectable semantic contract.

## What changed

- Stable `organon:*` identifiers, typed claims, explicit dependencies, profiles, and term-level provenance for all 82 binding terms.
- An Order-indexed institutional kernel covering standing, authority, permission claims, grants, admission, permission, revocation, exercise, enforcement, and scoped Witness independence.
- A stronger Lean experiment with explicit State feeding, executable Specifications, contextual Capability, and a nontrivial Boundary model that admits one Transformation and rejects an identity-breaking one.
- A machine-readable adoption manifest, schema, dependency-closure checker, and three initial profiles: agent, evidence, and governance.
- A repository structure separating ontology, editorial instruments, provenance, reviews, schemas, and examples.
- The first dogfood review against Kenogram, including a validated candidate adoption manifest and explicit conflict/refinement judgments.

## Verification

- Repository boundary links: passed
- Semantic registry and provenance: 82 terms, 19 typed commitments
- Example adoption: 3 profiles, 61 terms in dependency closure
- Kenogram candidate adoption: 3 profiles, 61 terms in dependency closure
- Lean 4.30.0: six build jobs passed; nontrivial finite model elaborated
- Lean source: no `sorry`, `admit`, or undeclared `axiom`

The Markdown ontology remains canonical. Lean remains a noncanonical instrument for making hidden commitments expensive.
