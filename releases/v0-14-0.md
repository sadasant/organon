# Organon v0.14.0

Organon v0.14 separates adaptive performance, functioning knowledge, and transmission from the artifacts that participate in them.

## What changed

- Added Intelligence as Agent-level Capability with one joined load-bearing path through Perception, Memory, Model, Interpretation, Action, and Consequence across States not individually named in the producing Rule's recorded Representation.
- Added Operative Knowledge as a discriminating Record-interpreter Configuration whose alternative Record changes Model, Interpretation, and Action and whose effect cannot bypass the selected Action; dormant storage, Truth, Evidence, and output alone remain distinct.
- Added Knowledge Transmission as recipient reconstruction of Operative Knowledge across distinct stages under a preservation Specification rather than literal Record copying; source and recipient may be the same persistent Agent.
- Added binding constraints C17-C19 and the optional `adaptive-knowledge` profile.
- Kept bare knowledge quarantined and made locally useful falsehood an explicit anti-collapse witness.

## Verification target

- Canonical Markdown ontology: one readable file
- Semantic registry and provenance: 93 terms, 29 typed commitments
- Existing example adoption: 3 selected profiles
- Lean 4.30.0 formal shadow: joined adaptive and fixed pipelines; explicit Rule encodings; capable and dormant interpretive contexts; useful false Operative Knowledge under a non-intelligent enumerating Rule; copied Record without recipient knowledge; inter-agent reconstruction; and self-transmission

The Markdown ontology remains canonical. The finite models test the proposed seams without claiming completeness of a supplied Rule encoding, a universal intelligence measure, runtime realization for deployed systems, semantic equivalence across arbitrary Records, transitive preservation, or a factive definition of bare knowledge.
