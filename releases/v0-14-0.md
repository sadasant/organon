# Organon v0.14.0

Organon v0.14 separates adaptive performance, functioning knowledge, and transmission from the artifacts that participate in them.

## What changed

- Added Intelligence as Agent-level Capability to construct or revise Models and Interpretations across non-enumerated States while producing Consequences conforming to one Specification.
- Added Operative Knowledge as a discriminating Record-interpreter Configuration with a specified result; dormant storage, Truth, Evidence, and output alone remain distinct.
- Added Knowledge Transmission as recipient reconstruction of Operative Knowledge under a preservation Specification rather than literal Record copying.
- Added binding constraints C17-C19 and the optional `adaptive-knowledge` profile.
- Kept bare knowledge quarantined and made locally useful falsehood an explicit anti-collapse witness.

## Verification target

- Canonical Markdown ontology: one readable file
- Semantic registry and provenance: 93 terms, 29 typed commitments
- Existing example adoption: 3 selected profiles
- Lean 4.30.0 formal shadow: adaptive and fixed pipelines; capable and dormant interpretive contexts; useful false Operative Knowledge; copied Record without recipient knowledge; and function-preserving reconstruction across different Records and Models

The Markdown ontology remains canonical. The finite models test the proposed seams without claiming a universal intelligence measure, runtime realization for deployed systems, semantic equivalence across arbitrary Records, transitive preservation, or a factive definition of bare knowledge.
