# Organon v0.10.0

Organon v0.10 makes discourse about consciousness governable without pretending that Organon has defined consciousness.

## What changed

- Added Consciousness Attribution as a Claim protocol whose Representation, Scope, meaning Rule, candidate Specification, and first-person or third-person provenance remain inspectable.
- Added Consciousness Designation as one Order-indexed CountsAs event connected to an admitted Attribution, Rule, institutional purpose, and Scope.
- Reserved Recognition for the recording of Standing and required a separate Rule for every downstream institutional effect of Designation.
- Added binding constraint C10: neither Attribution nor Designation entails candidate obtainment; non-designation does not decide it; failure to attribute or designate is Missingness only inside a field or Order that represents or expects the item.
- Kept the underlying consciousness condition quarantined and kept evidentiary disposition behind an explicit formalization gate.
- Added the optional `consciousness-discourse` adoption profile without changing the roots of the existing profiles.

## Verification target

- Canonical Markdown ontology: one readable file
- Semantic registry and provenance: 84 terms, 20 typed commitments
- Existing example adoption: 3 profiles, unchanged dependency closure
- Lean 4.30.0: ontology and consciousness attribution-designation countermodels elaborate
- Lean source: no `sorry`, `admit`, or undeclared `axiom`

The Markdown ontology remains canonical. Lean remains a noncanonical formal shadow that prices commitments and exhibits the stated anti-entailments.
