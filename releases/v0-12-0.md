# Organon v0.12.0

Organon v0.12 defines the field an Entity can inhabit without calling that field Reality, and the Configuration through which Transformations operate without calling that Configuration fundamental substance.

## What changed

- Added World: a scoped Configuration of participants, selected Environment, available Causal paths, and a named Invariant persisting across distinct constrained access paths.
- Added Substrate: a contextual Configuration whose persistent States Feed a named family of Transformations and whose Constraints shape their possible outputs.
- Added binding constraints C12 and C13 for the World-Reality-Map and carrier-carried anti-collapses.
- Added the optional `situated-world` adoption profile.
- Added explicit corpus provenance from *The Shadow of the World*, *Reasoning and Language*, and *Containment*.
- Recorded Uexküll, Gibson, Aristotle, and Simondon as local intellectual shadows with explicit non-inheritance boundaries.

## Verification target

- Canonical Markdown ontology: one readable file
- Semantic registry and provenance: 87 terms, 23 typed commitments
- Existing example adoption: 3 selected profiles
- Lean 4.30.0 formal shadow: participant-bound causal access witnesses, non-universal carrier Scope, non-identical access, and ordered source Persistence that does not entail invariant-preserving outputs; Reality and carrier-to-content realization remain explicit gates

The Markdown ontology remains canonical. The formal structures prove satisfiability and the named anti-entailments inside the finite shadow; they do not prove that the definitions exhaust Reality or every historical use of either word.
