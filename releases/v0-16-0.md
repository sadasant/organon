# Organon v0.16.0

Organon v0.16 makes six hidden bridge notions explicit without multiplying all six into new terms.

## What changed

- Declared cross-State identity criteria and Constraint-relative possibility in the metalanguage, with mandatory object-level witnesses for Entity and Capability Claims.
- Added Denotation, Causal Contribution, and Evidential Bearing as typed object Relations.
- Reduced generic use to existing named Relations and institutional eligibility to Standing.
- Strengthened Representation, Sign, Symbol, Model, Capability, Standing, Operationalization, World, Truth, Trust, Intelligence, Operative Knowledge, Knowledge Transmission, and Warranted Knowledge at the seams that previously relied on the hidden notions.
- Added C24, the no-hidden-bridge substitution constraint.

## Verification target

- Canonical Markdown ontology: one readable file
- Semantic registry and provenance: 107 terms, 35 typed commitments
- Lean 4.30.0 formal shadow: unequal Denotation, two-path Causal Contribution, constructive Capability realization, Standing without duplicate eligibility, supportive Evidential Bearing without Truth, Trust joined to canonical contribution, and Warranted Knowledge joined to recorded supportive bearing

The Markdown ontology remains canonical. The Lean witnesses test the promoted seams and named anti-entailments; they do not prove unique denotation, causal completeness, model fidelity for Capability, or the epistemic quality of an Order's evaluation Rule.
