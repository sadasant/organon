# Organon v0.17.0

Organon v0.17 adds the recurrent enactment mechanism through which participant-indexed Meaning can obtain and persist without adding a primitive.

## What changed

- Strengthened Flow with distinct ordered occurrences, a typed constructive Rule owning its exact Specification, Scope, and named persistence witness instead of introducing duplicate Recurrence.
- Added Ritual as participant-bound recurrent practice in which retained Memory makes a contrastive Difference to later Interpretation and the sustaining Causal Contribution passes through that Interpretation; one participant is sufficient.
- Added Meaning as the Relation sustained by Ritual, not significance stored inside its target or Records.
- Reduced ritual-derived effects to existing Record, Memory, Change, Consequence, Environment, Configuration, and Causal Contribution machinery rather than promoting Ritual Residue.
- Added C25-C29 and the optional `ritual-meaning` adoption profile.
- Kept Beauty, Play, Love, goodness, consent, consciousness, and moral worth distinct and unresolved.

## Verification target

- Canonical Markdown ontology: one readable file
- Semantic registry and provenance: 109 terms, 40 typed commitments
- Lean 4.30.0 formal shadow: repeated Flow whose typed Rule owns the exact occurrence Specification and whose exact output list carries an ordered Persistence witness; exact participant-history paths for every occurrence; a constructive `RitualUptake` for every later occurrence in which contrastive Memory changes Interpretation; unequal target States inside one target Persistence history and Invariant; private Ritual; Meaning with both contribution paths originating in the Ritual's Flow and both target origins proved identity-conforming; Flow and single-access structural insufficiency examples; derived-effect maintenance and dormancy classifiers; and causally propagated non-identical Meaning Relations

The Markdown ontology remains canonical. The Lean shadow uses proposal-local State roles for Perception, Memory, and Interpretation because OrganonCore does not yet expose their canonical structures. It also does not formalize represented-target Denotation, elapsed decay, Beauty, Play, Love, goodness, consent, consciousness, or moral worth.
